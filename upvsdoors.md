# Professional Prompt for Building a Complete UPVC Doors & Windows Business Web Application

Develop a modern, premium, AI-powered web application for **OUTLOOK ENTERPRISES**, a professional UPVC doors and windows company. The platform should feature a clean, responsive, and elegant user interface with smooth animations, fast loading speeds, and a mobile-first design. Create separate customer, administrator, and sales dashboards with secure authentication and role-based access control.

The website should include Home, About Us, Products, Projects Gallery, Services, Custom Design, Request a Quote, Blog, Testimonials, Contact, and Career pages. Provide an advanced product catalog where customers can browse UPVC windows, sliding doors, casement windows, French doors, partitions, and customized solutions with high-quality images, specifications, color options, dimensions, accessories, pricing requests, and comparison features.

Implement an intelligent quotation system that allows customers to submit project requirements, upload drawings or images, choose product configurations, and receive instant estimated quotations. Include lead management, CRM integration, appointment scheduling, WhatsApp communication, email notifications, inquiry tracking, order management, installation status, invoice generation, and customer support ticketing.

Design a powerful admin panel to manage products, categories, pricing, inventory, customer inquiries, quotations, orders, employee assignments, analytics, blogs, banners, and website content. Integrate dashboards with charts showing sales performance, lead conversion, monthly revenue, and customer engagement.

Optimize the application for SEO, accessibility, security, and scalability. Include multilingual support, dark mode, live chat, AI chatbot assistance, Google Maps integration, review management, analytics tracking, and cloud-ready deployment. Follow modern UI/UX principles using a premium glassmorphism aesthetic with professional typography, subtle gradients, and consistent branding to deliver an enterprise-grade digital experience that builds trust, generates qualified leads, and increases conversions for the UPVC business.
